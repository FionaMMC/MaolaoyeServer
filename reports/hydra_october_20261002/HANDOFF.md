## 同事先提供三类回执

1. **行情候选包**：在已获授权的 Windows QMT Python 中，从本仓库 `v2.3` 执行：

   ```powershell
   $HydraProducerCommit = (git rev-parse HEAD).Trim()
   python -m live_client.data_snapshot --as-of 20260930 --producer-commit $HydraProducerCommit --userdata-dir 'C:\实际live路径\userdata_mini' --output 'C:\private\hydra-october\snapshot-20260930'
   ```

   先确认仓库文件与 commit 一致，不用不相关 SHA 冒充来源。输出 ZIP、manifest、四流内容；本次补齐了逐证券最新日期检查与公司行动无响应拒绝逻辑。脚本会下载/读取 QMT 行情缓存到该 Windows 数据路径，不提交交易。文件直接交给 qmt 服务器私有研究/候选目录，先校验再进入正式导入链；不下载到本机研究工作区、不进 Git。单个 QMT 日历/行情缺响应要修复，不能手工填“成功”。

2. **当前账户事实与历史对账**：使用 `handoff/tools/collect_qmt_readonly.py --config C:\private\qmt-readonly.json --output C:\private\hydra-october\qmt-unique.json`。配置只含 `userdata_dir`、`account_id`、`expected_account_sha256`、一个不与现有进程冲突的正整数 `session_id`。脚本仅调用查询/连接接口，输出完整明细到 Windows 私有文件；屏幕回执只有哈希和数量。QMT 当前查询可能不含历史订单，所以还需旧批次对应本地 state/日志和券商历史委托/成交证据。不要把“查不到”改成“未成交”。账户为多策略共享时，账户总现金不能全算 Hydra 的钱。

3. **版本/任务清单与离线验收**：记录 `C:\hydra-live\config\active-release.txt`，用 `handoff/tools/Inspect-HydraTasks.ps1 -OutputDirectory C:\private\hydra-october\tasks-unique` 导出任务（只读、不改任务）。从仓库 `v2.3` 执行 `python -m live_client.offline_acceptance`，应返回 PASS；这仍不代表连接过真实 QMT。任务 XML 和账户文件仅走私有渠道。

本地工具测试入口：`python -m pytest reports/hydra_october_20261002/handoff/tools -q`。`check_readiness.py evidence.json` 验证证据清单，缺项退出码 2，不调用网关；即使字段全通过也不是交易授权。`lot_feasibility.py` 是乐观整手误差诊断，忽略费用/限价，不能作为已可执行计划。

## 十月执行安排与不达标处置

- 交易所国庆休市 10/1—10/7，10/8 开市；10/10 为周末休市。选定的第一对为 **10/8 收盘卖、10/9 开盘买**。如果本对未准备好，下一对为 10/12、10/13，不在周五卖完再把新买盘裸露到周一。[上交所公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20260915_10832273.shtml)
- 预先冻结权重及两阶段身份，卖出股数须用提交前已知信息形成；不能等收盘价出来后回填“当天按收盘成交”。实际成交价必须保留，影子账收盘价是比较基准。
- 卖出阶段后核实累计成交、持仓、资金归属和旧委托有效性。次日买入只用本策略实有资金；六笔卖款够六笔买单时，不等九笔全卖完。新政策下按明确优先级、同级剩余金额、证券代码排序；当前 client 不临场拆改冻结订单，比例缩量由 server 在新 attempt 前完成。
- 每轮原始目标份额上限不变。已成交跳过、未成交按实际现金/最新可用信息缩量。新估值导致的 A900/B600 不是新获批权重版本；A1000/B500 的旧轮不能自动变成补 B600。真正改变目标时，必须创建新版本并对**全组合实际持仓**算净差额。
- 最多三交易日包括第一次开盘买入日；按本次模拟 10/9、10/12、10/13 消耗窗口，10/12 开盘因跨周末跳过，10/12 收盘可作为 10/13 买入的参考阶段。不能把“三天”偷换为三次成功提交。
- 若资金不足、价格越界或整手导致本轮结束总欠配 >2%，保存残余及来源，不宣称完成；负责人审阅后可形成一次新版本的全组合净差额校正。不能靠每日全新目标滚动追加、不限期补单或未审阅的追价掩盖偏差。
- **研究尚未找到同时通过两条评估线的当前方案。** 基础跨日重算全期年化拖累约 0.475 个百分点、近期约 0.405，但最差欠配明显超 2%；25bp 滑点或回报晚一天会突破收益线。固定 5% 备用金本身约占用 0.377 个百分点全期年化，不能默认增加大额备用金就是更稳妥。

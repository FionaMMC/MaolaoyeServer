# V7.13 服务器影子账本审计

结论：**通用服务器账本实现和负向测试通过；三个正式 target 缺失，实例保持 blocked。**

实现范围：

- 独立 `shadow_instance_state`、`shadow_targets`、`shadow_nav_snapshots`；
- 统一八字段 target schema、单实例/单日期/哈希/日期/权重/证券代码校验；
- 卖先买后理论调仓、100 股 lot、佣金/最低佣金/印花税、虚拟现金、成本、换手和日 NAV；
- 同 target hash 只估值不重复调仓；价格缺失或陈旧 fail closed；
- 独立 scheduler 回调和 `/admin/shadow/summary`、`/admin/shadow/nav-history` 只读 API；
- 配置层拒绝 QMT account 和 `orders_enabled:true`；服务模块不导入订单/成交/RawSignal 模型。

负向测试确认 shadow run 后 `raw_signals/orders/trades` 均为 0。正式配置中的三个 target 文件当前均不存在，因此不会生成伪造 NAV。

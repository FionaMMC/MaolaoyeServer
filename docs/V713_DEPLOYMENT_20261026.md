## 二 兼容性说明（决定后续顺序）

- 当前 Windows 客户端（`1d0dd31` 时期）调用 `/oms/live/plan` 等 v1 接口。新服务器保留这些接口，v1 计划内容和哈希与原版本相同。
- **新服务器有一条保护规则：同一账户一旦有两个以上 live 实例，就把 v1 计划标为不可执行。**所以在 Windows 客户端升级到新版本（v2 `/oms/live/plans`）之前，**不能创建 V713 股票腿实例**，否则 Hydra 会停止交易。
